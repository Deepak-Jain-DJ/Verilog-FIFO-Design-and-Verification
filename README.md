# Verilog-FIFO-Design-and-Verification
32x16 FIFO Design and Self-Checking Verification Testbench in Verilog

## Features
- 32 depth FIFO
- 16 bit width
- Full flag
- Empty flag
- Simultaneous read/write support

## Verification
- Self-checking testbench
- Full flag verification
- Empty flag verification
- FIFO ordering verification
- Write when full verification

## Tools
- Verilog HDL
- EDA Playground
